## Gate Rules

- `done` 任务必须有 `Result=pass` 且 Reviewer 非作者；
- 开发任务必须同时有 RED 与 GREEN 证据；
- Gate 前不得有 skip/pending 测试或未解释的 flaky 结果；
- Phase 1 可执行产品路径总体分支覆盖率必须 >=80%，安全与策略分支必须有 100% fixture 覆盖；Phase 0 evidence-only helper 至少需要边界测试和非作者复核，若晋升为产品 Gate 则先补齐覆盖率；
- 命令、fixture 或 rubric 变化必须提升版本并保留旧结果；
- 隐私失败只保留脱敏路径和错误码，不保存敏感正文；
- Stop-ship 项失败时，相关任务不得以 partial pass 进入下一 Phase。
